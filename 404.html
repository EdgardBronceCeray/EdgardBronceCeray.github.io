# Cover images — drop them here Save each cover as `.jpg`, e.g. `B0H5Q3PQNY.jpg`. All three pages of the site (home, /zevaco/, /gaboriau/) read from this one folder, so you only add them once. If a file is missing, the page falls back to Amazon's cover endpoint, and failing that to a generated typographic cover — so nothing ever looks broken. But real files look best. Get them from KDP: Bookshelf -> the book -> Cover -> download. ~600x900 px JPEG is plenty. The full ASIN list is in ASINS.txt, next to this file.
